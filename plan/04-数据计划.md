## 一、数据分层

```
真实抓取（联网、本地、永不入仓）
        │  仅个人低频使用，ToS 边界
        ▼
snapshots/  ← gitignore，可复跑、可核对、不可分发
        │  人工触发、按 (source, fund_code, period) 缓存
        ▼
运行期台账  ← local_data/ + out/，gitignore
        │
        ╳ 不跨越这条线
        │
data/fixtures/  ← 入仓：全部为合成快照（sample: synthetic）
data/config/    ← 入仓：冻结配置包（规则数据，非业务数据）
```

**硬红线**：仓库内不存在任何真实抓取的持仓/规模/经理数据。fixtures 的每一个数值都由生成器用确定性 RNG 造出，文件头写 `"sample": "synthetic"`。

## 二、合成快照设计（M1 交付）

### 2.1 覆盖矩阵

| 维度 | 取值 | 最少样本 |
|---|---|---|
| 持仓变动 | 新进 / 退出 / 加仓 / 减仓 / 不变 | 每类 ≥1，且同一基金内出现多类 |
| 经理状态 | `in_period` / `prior_period` / `none` / `unparsed` | 各 ≥1 |
| 规模状态 | 正常变动 / `no_prev_baseline` / 期间零申赎（真 0） | 各 ≥1 |
| 基金类型 | 股票型 / 混合型 / ETF 联接（无股票持仓） / QDII（行业字段缺失） | 各 ≥1 |
| 异常 | `ratio=null`、`stock_code` 非法、`change_type` 缺失、页面解析失败、网络失败 | 各 ≥1 |

`coverage` 段逐类型登记 `total` / `sampled`，并写 `"note": "抽样覆盖、非穷举"`。

### 2.2 目录与文件

```
data/fixtures/
├── MANIFEST.json                 # 逐文件 sha256 + generator version + seed
├── q2026q2/                      # 上季
│   ├── holdings/<code>.json      # 归一持仓（plan/03 §1.2）
│   ├── events/<code>.json        # 经理 + 规模
│   └── disclosure.json           # eid 元数据快照
├── q2026q3/                      # 本季（同结构）
└── truth/
    ├── diff_truth.json           # 真值：输入 + 期望状态（不含 observed_*）
    ├── events_truth.json         # 经理/规模期望
    └── coverage.json             # 覆盖矩阵
```

**真值纪律**：`truth/*.json` 只存"输入指针 + 期望状态 + 期望计数"；**禁止出现 `observed_*` 字段**，观测由 `bench`（M3 落地）运行时实算。期望值必须能由输入独立复算（例如"新进"= 上季无该代码且本季有，不依赖 diff 引擎实现）。

### 2.3 生成器

`tools/gen_fixtures.py`（M1 落地）：

- 自研 splitmix64 RNG，固定 `seed`（写进 MANIFEST）；
- **禁** stdlib `random`、**禁** set 迭代序、**禁**系统时钟；
- 产物无时间戳；两次运行逐字节一致；
- `--check`：重新生成到临时目录，与冻结产物逐字节比对（两层守门：产物形态 + 重生成结果）；
- `--out DIR`：输出到指定目录（供测试用临时目录，避免污染）。

**真值同源但独立实现**：生成器先造"两季持仓"，再按**独立于 diff 引擎的规则**写出期望状态（例如直接由生成时的注入意图记录），diff 引擎读 fixtures 自行计算——两侧不共享判定函数。

### 2.4 数据命名

- 基金代码沿用真实格式（6 位数字），但**全部为虚构组合**，不与真实基金对应；文件头 `name` 加"（样例）"语义由 `sample` 字段承担，不写进 name；
- 报告与 README 均标注"基准日快照样本 / 合成数据"。

## 三、真实数据使用纪律（联网路径）

| 纪律 | 落地 |
|---|---|
| 仅个人本地低频 | 同域名串行 + 固定最小间隔（配置） |
| 不建公开镜像 | 抓取结果落 `snapshots/`，gitignore |
| 不再分发原始数据 | 仓库无任何真实响应；fixtures 全合成 |
| 不绕反爬 | 429/403/验证码/登录 → 停止 + 落台账 + exit 4 |
| 不写死接口条数 | 解析按结构，不按"应返回 N 条"断言 |
| 单位读表头 | `gmbd` 单位从表头解析，不硬编码 |
| 期间标识 | 用 `data_date`（报告期截止）而非抓取日；两期相同即拒绝 |

### 3.1 缓存键

`(source, fund_code, report_period)` → `snapshots/<source>/<code>/<period>.raw` + `.meta.json`。
同一运行内不重复请求；跨运行命中缓存则零网络。

### 3.2 失败台账

`local_data/failures.json`：`{fund_code, source, error_kind, http_status, retries, ts}`。`error_kind ∈ {timeout, http_4xx, http_5xx, decode_error, parse_error, blocked, structural}`。`blocked` 单独一类（不做规避的证据）。

## 四、M1 数据先行清单（开工第一棒）

1. `data/config/app.json` 冻结：窗口、`diff.mode=computed` + `threshold`、限频/退避、合规词表、来源注册表、排序约定；
2. `tools/freeze_config.py` + `MANIFEST.json` + `--check`；
3. `tools/gen_fixtures.py` + 两季快照 + 真值 + coverage；
4. 覆盖矩阵逐类样本齐备，`--check` 绿；
5. `data/README.md` 增补"合成快照清单"小节（只登记文件名与覆盖维度，不复制数值）。

> 顺序不可颠倒：**配置冻结 → 生成 fixtures → 写测试**。先写测试再定配置，会出现"测试里藏着第二份口径"。
