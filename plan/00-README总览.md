# plan/00-README 总览

仓库 `10-18-fund-holdings-diff`（基金季报持仓变动监控）出题阶段总览。v1（2026-10-17，出题阶段 4 骨架完成）。

**项目**：维护自选基金清单 → 抓季报前十大持仓 → 与上季做 diff（新进/退出/加仓/减仓）→ 叠加基金经理变更与规模变动 → 生成"这一季我的基金换了什么"的本地报告。
**方法论**：数据先行 + 官方元数据定序 + 双通道抓取 + 冻结判定口径 + 合成真值基准 + 确定性产物。
**交付形态**：**纯本地 Python CLI + 本地季报报告（Markdown + 单文件 HTML）**（无服务器、无 GPU、无账号体系、无数据上传）。
**命名约定**：本地目录与 GitHub 仓库名均为 `10-18-fund-holdings-diff`；署名 `yuluo554`。
**定位宣言**：维护自选基金清单 → 抓季报前十大持仓 → 与上季做 diff（新进/退出/加仓/减仓）→ 叠加基金经理变更与规模变动 → 生成"这一季我的基金换了什么"的本地报告。**不是实时估值工具，是季度事件回顾**。竞品停在"爬取/汇总"层，没人把"季度 diff + 经理变更 + 规模变化"合成一份可读季报。
**品牌隔离**：本题只做**公募基金季度报告**；与同系列其他项目（含上市公司公告类）零代码复制、文档互不提及。

## 五、纪律

- **不写会随实现漂移的硬数字**（测试数 / 用例数 / 通过数 / 代码行数）；接口返回的条数/条目录入为**基准日快照**，不写进代码常量，实现以实时解析为准。指标只写口径与门槛来源，确需数字"以末态回填"。
- **数值口径一处定义**（`data/README.md §四`），引擎 / 报告 / 基准全部引用同一份，禁止手写第二份口径。
- **冻结产物禁手改**（配置包、真值台账、合规词表）：改需求走生成器整目录重生成 + `--check` 位级守门。
- **限制必须如实写**：低频、ToS、巨潮滞后三条是**结构性限制**，plan/01 与 README 均不得粉饰或省略。
- **不得声称空白**：开源现状一律写"空白度低"，并列出 `investool` 等竞品的边界。
- **诚实口径**：未推送 = 未跑 CI；DoD 中的"CI 绿"在无远端时必须写成"本地等价校验，待首推验证"。
- **每个里程碑出口的硬约束**：DoD 验证 → 本文件状态回写 → 写 `plan/HANDOFF-M<next>.md` → commit →（有远端则 push 等 CI 绿）。
- **隐私红线**：自选清单纯本地；仓库内不提交真实抓取的全量数据，样例一律合成快照。
- **品牌隔离**：文档只写"公募基金季报"，不提及任何其他项目；与上市公司公告类项目硬切割。
- **发布纪律**：M6 三件套措辞不裁剪；发布留档在 tag 前落盘，tag 后才产生的事实（CI run id / 附件 sha256 / 下载复核）作为追加提交并**分栏**记录。
