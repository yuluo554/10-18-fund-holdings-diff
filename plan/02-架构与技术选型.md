## 一、技术定位（一句话）

**一个纯本地、零运行时第三方依赖的 Python CLI**：输入是本地自选清单，输出是一份可审计的季度变动台账 + 一份零外链单文件 HTML 季报；**全流程离线可用**，联网只发生在显式触发的抓取子命令里。

三条不可让渡的形态约束（来自 plan/01 §六）：

1. **纯本地**：无服务器、无账号、无遥测、无上传；自选清单只落本机。
2. **确定性**：同一输入两次运行，台账与报告**逐字节一致**；判定规则冻结在配置包，可回放。
3. **可审计**：每条变动携带两季原始记录指针；来源标注区分"官方披露"与"商业接口"。

## 二、运行形态与命名

| 项 | 结论 | 理由 |
|---|---|---|
| 语言 | Python **≥ 3.8** | 本机双通道（3.8.8 / 3.12.10）可实跑；CI 矩阵 `{ubuntu-22.04, windows-latest} × {3.8, 3.12}`；代价是禁用 3.9+ 语法（`dict \| dict`、`list[int]` 注解、`Path.write_text(newline=)`） |
| 分发名 / 包名 | `funddiff` | 短、可作模块名与命令名；与仓库名 `10-18-fund-holdings-diff` 解耦，编号只留在仓库名 |
| 入口 | `python -m funddiff` **与** 控制台脚本 `funddiff` | 两条通路 `sys.path` 来源不同，CI 与冒烟两形态都跑（skill 安装面第四面） |
| 运行时依赖 | **零第三方**（`argparse` / `json` / `urllib` / `decimal` / `hashlib` / `tempfile`） | 安装面最小、代理与证书差异最少、CI 首推即绿概率最高 |
| 开发依赖 | `pytest`（`.[dev]`） | 测试面 = 安装面 = README 指令面 |
| 存储 | **JSON + 原子写**（清单、台账、配置） | 单用户低频数据量（清单 5–20 只、每只 10 行）；字节确定性强，双跑一致可直接断言；SQLite 的二进制库文件不便做字节级确定性守门 |
| CLI 解析 | `argparse` 子命令 | 零依赖；`build_parser()` 可被 README 门禁反射核验 |
| HTML 渲染 | 自写最小 writer（字符串拼接 + 转义） | 报告要求零外链零 CDN；模板引擎会引入依赖且容易带外部资源 |
| 并发 | 无（串行） | 限频纪律要求同域名串行；数据量小，并发无收益且破坏确定性 |

### 2.1 被否掉的选项（决策留痕）

| 选项 | 否掉的理由 |
|---|---|
| SQLite 存清单与台账 | 天然唯一键很香，但库文件是二进制、跨平台字节不承诺一致，"同输入双跑逐字节一致"这条验收会从"可断言"退化成"只能断言业务字段"。幂等性在 JSON 存储里用代码层唯一键（`sorted + 覆盖`）同样可达，且更易测 |
| `requests` / `httpx` | 引入安装面与代理/证书差异；`urllib` 足以覆盖 GET + 超时 + 重定向，且能精确控制编码 |
| Jinja2 / 其它模板引擎 | 单文件 HTML 的结构固定且简单；模板引擎是额外安装面，还容易默认带 CDN 片段 |
| pandas | 数据量小；引入大依赖且浮点/NaN 语义会污染"缺失 ≠ 0"的判定 |
| 异步抓取 | 与"同域名串行 + 固定间隔"的限频纪律直接冲突；先做对再谈快 |
| 把配置打进 wheel 的 `package-data` | 配置是**可审计的数据资产**，不是代码；打进去会让"改配置要重装"。改为仓库内 `data/` + `--data-dir` 显式寻址（非 editable 安装时必传，README 写明） |

## 四、退出码契约（全项目唯一一份，锁进测试）

| 码 | 语义 | 典型场景 | 是否故障 |
|---|---|---|---|
| `0` | 成功 / 谓词成立 | 清单增删查、窗口计算、报告生成且合规 | — |
| `1` | **门禁不通过**：有结论但结论是"不达标" | `selftest` 有检查失败；合规词表命中；基准与真值不符 | 否，是既定语义 |
| `2` | **用法或输入错误** | 未知子命令、参数缺失、基金代码非法、日期非法、配置缺失/损坏 | 是（用户可修） |
| `3` | **该阶段尚未就绪** | 骨架期 M2–M5 子命令（`fetch/diff/managers/scale/report/run`） | 否，是显式契约 |
| `4` | **上游/网络不可用** | 抓取超时、限频命中、验证码、登录墙（落台账后退出） | 是（环境/上游） |
| `5` | 内部一致性错误 | 冻结配置与 MANIFEST 不符、序列化失败、不可达分支 | 是（需修） |

纪律：

- `3` 是**临时契约**，随模块落地逐条退役；退役时要同步删掉对应的"期望 exit 3"断言，并补一条真实能力的离线冒烟（skill 退役纪律）。
- 每个子命令的码语义写进 README 命令表；测试用参数化锁死。
- **禁止**"未实现但返回 0"的空壳入口（`return 0` / `return True`）——骨架期一律 exit 3 并打印原因。

## 五、冻结配置包

`data/config/` 是本项目的**规则数据层**，与代码分离：

| 文件 | 内容 | 冻结方式 |
|---|---|---|
| `app.json` | 季度窗口、`diff.mode` + 阈值、限频/退避、合规词表、来源注册表、排序约定 | `tools/freeze_config.py` 生成 `MANIFEST.json`（逐文件 sha256 + `config_version`） |
| `MANIFEST.json` | 生成物，禁止手改 | `--check` 重算比对，不一致 exit 1 |

加载规则（`config.py`）：

- **必需键缺失 → exit 2**，不做"聪明默认值"；
- `diff.mode` 必须显式出现，取值只能是 `provider` / `computed`，**不允许缺省推断**；
- 数值型参数以**字符串**存 JSON、以 `Decimal` 入内存（避免二进制浮点漂移）；
- 季度窗口里未按法规原文核对的项带 `unverified: true`，报告与 CLI 输出必须原样透出该标记，**不得当成"已核实"**。

> 为什么配置要冻结：M3 的判定口径、M5 的合规词表都会影响产物字节。允许手改配置 = 允许产物在无代码变更的情况下漂移，基准与"双跑一致"就失去意义。

## 六、确定性设计（跨模块约定）

| 关注点 | 约定 |
|---|---|
| 写盘 | **唯一出口** `serialize.write_json()`：`json.dumps(sort_keys=True, ensure_ascii=False, indent=2)` + `\n` 结尾 + 显式 UTF-8（`newline="\n"`）；写临时文件后 `os.replace` 原子替换 |
| 读取 | 一律 `encoding="utf-8"` 显式声明；GBK 只出现在 `net/eastmoney.py` 的页面通道，且解码失败即抛错并保留原始字节快照 |
| 时间 | **业务逻辑不读系统时钟**。`--as-of` 决定窗口；缺省时才取当天，并在输出中打印实际使用日期。台账/快照**不写生成时间戳** |
| 排序 | 台账：基金代码升序 → 本季占比降序（`Decimal` 比较）→ 股票代码升序；清单纯代码升序 |
| 数值 | 占比用 `Decimal`，序列化前统一 `quantize`；**缺失写 `null`，不写 `0`** |
| 随机 | 合成数据生成器自研确定性 RNG（splitmix64），**禁用 stdlib `random` 与 set 迭代序** |
| 时钟格式 | 若某产物必须带时间，只允许 `YYYY-MM-DDTHH:MM:SSZ` 且单独列为"非确定性字段"并写进 K 清单 |

## 七、数据目录解析（安装面）

`paths.resolve_data_dir(explicit)` 的查找顺序：

1. `--data-dir`（显式，最高优先级；不存在或缺 `config/app.json` → exit 2）；
2. 环境变量 `FUNDDIFF_DATA_DIR`；
3. 当前工作目录下的 `data/`；
4. 包文件向上查找（`src/` / 仓库根布局）得到的 `data/`；
5. 都未命中 → exit 2，提示"请用 `--data-dir` 指向仓库的 data/ 目录"。

`--store` 默认 `<cwd>/local_data/watchlist.json`（`.gitignore` 已隔离）；写前才创建目录。

> 非 editable 安装（`pip install .`）时配置不在 wheel 内，**必须** `--data-dir`；README 与 `--help` 都写这句，避免"装完就能跑"的错觉。这一条是 M6 发布物本体复核的必查项。

## 八、网络层（M2 落地，M0 只留结构）

- **所有**网络 import 只在 `funddiff/net/`；其它模块出现 `socket/urllib/http/ssl/requests` 即测试失败（M0 起生效）。
- 双通道：`FundMNInverstPosition`（JSON 首选）→ 缺失/字段不全回落 `jjcc` 页面（GBK + 内嵌 JS 正则）；回落事实写入台账并在报告中可见。
- 限频：同域名串行 + 固定最小间隔；指数退避参数全部来自配置；命中 429/403/验证码/登录 → 停止该域名后续请求，落台账，exit 4，**不规避**。
- 失败隔离：单只基金失败不影响其余；失败原因进逐基金状态台账。
- 缓存：`(source, fund_code, report_period)` 为键；抓取产物落 `snapshots/`（gitignore），永不入仓。

## 十、风险与缓解

| 风险 | 影响 | 缓解 |
|---|---|---|
| 东财页面结构变更 | 页面通道解析失败 | JSON 通道优先；页面通道失败按失败隔离落台账；fixtures 覆盖结构差异 |
| GBK 解码失败 | 静默丢字符会污染台账 | 显式解码 + 失败保留原始字节并报错，测试覆盖 |
| Q1/Q2/Q4 披露期限未经原文核对 | 窗口判定可能错 | 配置标 `unverified: true` 并原样透出；M1 按法规原文核对后翻转 |
| 配置与代码漂移 | 产物不可复现 | 配置 MANIFEST + `--check`；口径数值零内嵌门禁（M3 起） |
| 非 editable 安装找不到 data/ | 用户装完即失败 | `--data-dir` 显式契约 + README 快速开始两条路径 + M6 本体复核 |
| 低频数据导致"看起来没用" | 认知落差 | README 第一屏把低频写成定位（季度事件回顾），演示用历史季度回放 |
