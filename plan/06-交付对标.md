## 三、边界 → 落地防线

| 边界（plan/01 §六） | 代码/工程防线 | 验法 |
|---|---|---|
| 非投资建议 | 合规词表硬门禁 + 固定页脚 | 注入违规文本 → exit 1 |
| 不做实时估值 | 不接行情接口；只读季报 | 代码面零行情端点（静态扫描来源注册表） |
| 不做筛选推荐 | 无评分/排序模块 | 报告字段扫描无排名类键 |
| 不做公开镜像/再分发 | `snapshots/` gitignore + 合成 fixtures | 仓库内真实数据扫描（M6 已做，0 命中） |
| 不绕反爬 | 429/403 → 停止 + exit 4 | 构造 blocked 样本 |
| 不承诺全覆盖 | coverage 登记 total/sampled | `coverage.json` + README |
| 低频是定位 | README 第一屏 + `report` 页眉写报告期 | 文档审阅 |
| 隐私红线 | 纯本地存储、无账号、无上传 | AST 零网络门禁（net/ 之外）+ 存储路径 gitignore |
| 品牌隔离 | 文档只写公募基金季报 | 发布前文书复查 |
