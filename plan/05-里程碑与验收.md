## 三、每个里程碑的固定收尾流程

```
DoD 验证 → plan/00、05、06 状态回写 → 写 plan/HANDOFF-M<next>.md
        → commit →（有远端则 push 等 CI 绿）
```

- 无远端期间：DoD 写"本地等价校验（未接远端，CI 待首推验证）"，**禁止写"CI 绿"**。
- HANDOFF 库内一律相对路径；绝对路径只出现在用户侧启动命令里。

## 四、演示脚本（每棒都能跑）

```bash
# M0
py -3.12 -X utf8 -m funddiff --help
py -3.12 -X utf8 -m funddiff watch add 000001 --name "样例基金"
py -3.12 -X utf8 -m funddiff watch list
py -3.12 -X utf8 -m funddiff window --as-of 2026-10-18
py -3.12 -X utf8 -m funddiff selftest

# M1
py -3.12 -X utf8 tools/freeze_config.py --check
py -3.12 -X utf8 tools/gen_fixtures.py --check

# M2
PYTHONPATH=src py -3.12 -X utf8 -m funddiff fetch --fund 000001 --period 2026Q3

# M3–M4（已落地）
py -3.12 -X utf8 -m funddiff diff --mode computed --period 2026Q3
py -3.12 -X utf8 -m funddiff managers --period 2026Q3 --json
py -3.12 -X utf8 -m funddiff scale --period 2026Q3 --json

# M5（落地后逐条替换 stub）
py -3.12 -X utf8 -m funddiff run --as-of 2026-10-18 --out-dir out
```

> 所有演示默认带 `--store` / `--out-dir` 指向临时目录，避免污染开发者本机 `local_data/`（skill 的"测试隔离真实主目录"条）。
